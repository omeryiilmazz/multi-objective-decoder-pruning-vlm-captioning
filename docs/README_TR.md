# Türkçe Not

Bu klasör GitHub'a profesyonel şekilde yüklenmek üzere düzenlenmiş sürümdür.

Önemli kararlar:

- Dosya adları İngilizce, küçük harfli ve boşluksuz hale getirildi.
- Notebook çıktıları temizlendi.
- Hugging Face token'ları silindi.
- Kromozom JSON dosyaları model bazında ayrıldı.
- Proxy COCO 200 veri klasörü `data/proxy_coco_200/` altına alındı.
- Ana dokümantasyon İngilizce yazıldı; bu akademik görünüm açısından daha doğru.

GitHub'a yüklemeden önce `README.md`, `CITATION.cff` ve `LICENSE` dosyalarındaki isim/yıl bilgilerini son kez kontrol edin.
